# 🦉 Pintar Matematika SD

Aplikasi pembelajaran matematika untuk siswa Sekolah Dasar kelas 1–6.

## Fitur
- Beranda pembelajaran
- Materi dan rumus matematika
- Kalkulator
- Kuis matematika
- Progres belajar

## Persyaratan
- Python 3.10 atau lebih baru
- Koneksi internet untuk instalasi pustaka

## Menjalankan di Windows

Buka terminal di folder proyek, lalu jalankan:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Buka http://localhost:8501 di browser.

## Menjalankan di Linux

```bash
chmod +x run.sh
./run.sh
```

## Menjalankan di Streamlit Community Cloud

1. Unggah seluruh file proyek ke GitHub.
2. Buka https://share.streamlit.io/
3. Hubungkan akun GitHub.
4. Pilih repositori pintar-matematika-sd.
5. Pilih branch main dan file utama app.py.
6. Tekan Deploy.
